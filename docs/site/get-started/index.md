# Get started

This section takes a host from no daemon to a running tailnet. Read the pages in this
order:

1. [Requirements](requirements.md) states what the host needs.
2. [Install](install.md) installs a released binary, or builds the binary from source.
3. [Quick start](quick-start.md) writes the configuration and starts the first tailnet.

After the quick start, read the [Guides](../guides/index.md) to use the console.
